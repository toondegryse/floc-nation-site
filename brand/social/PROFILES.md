# Social profiles

The same picture, name and bio line on all four channels, so they read as one brand. The files are in this folder (`brand/social/`), except the Facebook cover, which is on the "Floc Nation logo" canvas. This file is the reference. For the step-by-step list, with the same bios ready to copy, use `UPLOAD.md`.

**The core line.** Every bio starts with it:

```
Brewed and built in Bangkok. Home brewing problems and the tools that fix them.
```

**Website link.** Add the website link after go-live (gate G3). Until then, leave the link fields empty.

**Limits.** The character limits below were right as far as known in November 2026. Platforms change them, so check the counter in the app when you paste. Counts include spaces, and a line break counts as 1.

**Menus.** App menus move around. If a step doesn't match your screen, look for "Edit profile" (or "Edit channel" on YouTube).

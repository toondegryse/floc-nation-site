# Floc Nation website

The home base of Floc Nation, home brewing and brewing automations from Bangkok, plus a priming-sugar calculator.

- Brief: `PROJECT.md`
- Who's on what: `BOARD.md`
- Latest check-in: `STATUS.md`
- Preview: https://toondegryse.github.io/floc-nation-site/

Run the tests with `npm test` (Node 18 or newer, no packages needed).
